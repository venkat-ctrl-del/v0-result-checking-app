================================================================================
                      🚀 QUICK 3-STEP DEPLOYMENT
================================================================================

STEP 1: CREATE DATABASE (Supabase) - 5 minutes
────────────────────────────────────────────────

1. Go to https://supabase.com
2. Click "Start your project"
3. Sign up with email
4. Create new project:
   - Name: exam-monitor
   - Password: [strong password]
   - Region: [closest to you]
5. Wait 2-3 minutes...
6. Go to Settings → API
7. Copy and save:
   - NEXT_PUBLIC_SUPABASE_URL = [Project URL]
   - NEXT_PUBLIC_SUPABASE_ANON_KEY = [anon public]

CREATE TABLES:
1. Go to SQL Editor
2. Create new query
3. Copy-paste from: scripts/01-init-schema.sql
4. Click "Run"
5. Go back and run: scripts/02-add-missing-tables.sql
6. Done! All tables created.

✓ STEP 1 COMPLETE


STEP 2: DEPLOY APP (Vercel) - 3 minutes
────────────────────────────────────────

1. In v0 dashboard, click "Publish" (top-right)
2. Choose deployment option
3. Authorize with Vercel
4. Enter project name
5. Click "Create & Deploy"
6. Wait 2-3 minutes...
7. You get a URL: https://yourapp.vercel.app

✓ STEP 2 COMPLETE


STEP 3: ADD CREDENTIALS (2 minutes)
────────────────────────────────────

1. Go to https://vercel.com/dashboard
2. Click your project
3. Go to Settings → Environment Variables
4. Add these variables:

   NEXT_PUBLIC_SUPABASE_URL
   = [from Supabase Step 1]

   NEXT_PUBLIC_SUPABASE_ANON_KEY  
   = [from Supabase Step 1]

5. Click "Save"
6. Go to Deployments tab
7. Click latest deployment
8. Click "Redeploy"
9. Wait 1-2 minutes...
10. Status shows "Ready"

✓ STEP 3 COMPLETE - YOU'RE LIVE! 🎉

================================================================================
                      🚨 TROUBLESHOOTING
================================================================================

BLANK PAGE AFTER DEPLOYMENT:
───────────────────────────
1. Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
2. Check browser console for errors (F12)
3. Verify environment variables are set correctly
4. Check Vercel deployment logs

CAN'T ADD CANDIDATES:
─────────────────────
1. Check NEXT_PUBLIC_SUPABASE_URL is correct
2. Check NEXT_PUBLIC_SUPABASE_ANON_KEY is correct
3. Verify tables exist in Supabase SQL Editor
4. Check browser console (F12) for error messages

NOTIFICATIONS NOT SENDING:
──────────────────────────
1. Verify RESEND_API_KEY is correct (if using email)
2. Verify TWILIO credentials are correct (if using SMS/WhatsApp)
3. Check Results tab for error messages
4. Verify contact details are valid

DEPLOYMENT FAILED:
──────────────────
1. Check Vercel build logs
2. Verify all environment variables are set
3. Try redeploying
4. Check project settings in Vercel

→ See DEPLOYMENT.md Troubleshooting for more help
